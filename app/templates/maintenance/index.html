Gestión de Base de Datos
Zona de Alto Riesgo

Resetear Base de Datos

Elimina todas las tablas y recrea la estructura de la base de datos desde cero. Útil para resolver problemas de corrupción o para empezar de nuevo.

  • Se crea automáticamente un backup antes de proceder
  • Todas las tablas serán eliminadas y recreadas
  • Los datos iniciales (extensiones, tipos de soporte) se pueden repoblar
  • Los datos de usuario (películas, escaneos) se perderán
